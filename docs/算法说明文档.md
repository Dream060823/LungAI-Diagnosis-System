# 肺结节CT影像AI辅助诊断系统 - 算法说明文档

## 一、模型选型

### 1.1 分类模型：ResNet-50

本系统采用 ResNet-50 作为肺结节良恶性分类模型。

ResNet-50（深度残差网络）是微软研究院于2015年提出的深度学习模型，在 ImageNet 图像分类竞赛中获得冠军。其核心创新是"残差连接"（Skip
Connection），通过跳跃连接解决了深层网络训练困难的问题，使得网络可以达到50层的深度。

选择 ResNet-50 的原因：
- 预训练权重丰富：已在 ImageNet 数据集（包含1400万张图片、1000个类别）上训练完成，具备强大的图像特征提取能力
- 迁移学习效果好：医学影像的底层特征（边缘、纹理、形状）与自然图像相似，迁移学习效果显著
- 计算效率高：相比3D模型，2D方案参数量小、推理速度快，可在普通笔记本CPU上流畅运行

### 1.2 模型结构

输入层：224 × 224 × 3（RGB图像）
    ↓
卷积层 + 残差块 × 49层（layer1-layer4）
    ↓
全局平均池化层
    ↓
全连接层1（2048 → 512）+ ReLU + Dropout(0.7)
    ↓
全连接层2（512 → 128）+ ReLU + Dropout(0.5)
    ↓
全连接层3（128 → 2）
    ↓
输出层：良性概率、恶性概率

原始 ResNet-50 输出1000个类别（ImageNet的1000类物体），本项目将其最后的全连接层修改为3层结构，输出2个节点，对应肺结节的"良性"和"恶性"两个分类。同时解冻 layer3 和 layer4 进行微调，以提高模型对医学影像特征的提取能力。

## 二、数据预处理流程

CT影像输入模型前，需经过以下预处理步骤。系统支持两种输入格式：
- DICOM格式（.dcm）：用于真实的CT影像分析
- 普通图片格式（.jpg/.png）：用于测试和演示

### 2.1 DICOM文件读取

CT影像以DICOM格式（.dcm）存储，使用pydicom库读取。DICOM文件包含像素数据和元数据（患者信息、扫描参数等）。

### 2.2 CT值转换

DICOM文件中存储的原始数值需通过以下公式转换为真实的CT值（Hounsfield Unit, HU）：

HU = 原始值 × RescaleSlope + RescaleIntercept

CT值范围通常为-1000（空气）至+3000以上（骨骼），不同组织具有不同的CT值范围。

### 2.3 窗宽窗位调整

针对肺部CT，设置肺窗参数：
- 窗位（Window Center）：-600 HU
- 窗宽（Window Width）：1500 HU

通过窗宽窗位将CT值映射到0-255的灰度范围，突出肺实质结构，便于模型识别肺结节特征。

### 2.4 空间归一化

将所有影像统一调整为 224 × 224 像素，满足 ResNet-50 的输入尺寸要求。

### 2.5 通道转换

CT影像为灰度图（单通道），ResNet-50 要求3通道输入。将灰度图复制为3个相同通道。

### 2.6 数值归一化

将像素值从 0-255 归一化到 0-1 范围，提高模型训练稳定性和收敛速度。

## 三、模型推理流程

1. 输入：预处理后的CT影像张量，形状为 (1, 3, 224, 224)
2. 前向传播：将张量输入 ResNet-50 模型，得到原始输出值
3. Softmax归一化：将原始输出转换为概率分布
4. 分类判断：取概率较大的类别作为预测结果（0=良性，1=恶性）
5. 输出：良性概率、恶性概率、判断类别

## 四、可解释性设计（CAM热力图）

### 4.1 技术原理

采用 GradCAM（梯度加权类激活映射）技术，通过分析模型最后一个卷积层的梯度信息，生成类激活热力图，可视化模型做出判断时重点关注的图像区域。

### 4.2 实现方式

- 使用 pytorch-grad-cam 库实现
- 目标层：ResNet-50 的 layer4 最后一个卷积层
- 输出：热力图叠加在原始CT影像上，红黄色区域表示模型重点关注区域

### 4.3 结节定位（基于CAM热力图的边界框提取）

除了生成可视化热力图外，系统还利用CAM热力图实现结节的自动定位。具体步骤：

1. 对CAM热力图进行高斯模糊，减少噪声
2. 取前15%高激活区域作为候选结节区域
3. 进行形态学操作（膨胀+腐蚀），填充小孔洞，使区域更完整
4. 使用OpenCV轮廓检测提取边界框
5. 按面积排序，取前3个最大区域（最多报告3个结节）
6. 将坐标从224×224映射回原始影像尺寸，并添加10%的padding

这种方法属于弱监督定位（Weakly Supervised Localization），利用分类模型的注意力信息实现定位功能，无需额外的检测模型。

### 4.4 临床意义

热力图和边界框可以帮助医生理解AI的判断依据。例如，当AI判断结节为恶性时，热力图可能高亮显示结节边缘的毛刺区域或分叶区域，与临床影像学特征一致，增强医生对AI辅助诊断结果的信任度。

## 五、数据集与训练

### 5.1 数据来源

本系统使用 COCO 格式的 LUNA16 数据集进行模型训练。LUNA16 是基于 LIDC-IDRI 数据库的公开数据集，专门用于肺结节检测竞赛。

数据集包含：
- 训练集：869 张结节图片
- 测试集：217 张结节图片
- 标注格式：COCO JSON（包含边界框坐标）

### 5.2 训练方法

采用迁移学习方法，使用 ImageNet 预训练的 ResNet-50 作为基础模型，通过以下步骤进行微调：

1. 冻结 ResNet-50 前面的卷积层
2. 解冻 layer3 和 layer4 进行微调
3. 修改最后的全连接层为 3 层结构（512→128→2）
4. 使用 Dropout（0.7 和 0.5）防止过拟合
5. 训练 10 个 Epoch，学习率 0.0005

### 5.3 训练结果

经过10个Epoch的微调训练，模型在验证集上达到 99% 以上的准确率。需要注意的是，该数据集为二分类任务（结节 vs 非结节），数据量较小（训练集869张、测试集217张），实际临床应用中需要更大规模的数据集进行验证。

## 六、技术栈

| 组件 | 技术 | 用途 |
|------|------|------|
| 深度学习框架 | PyTorch | 模型加载、推理计算 |
| 预训练模型 | ResNet-50 (torchvision) | 图像特征提取与分类 |
| DICOM读取 | pydicom | 读取CT影像文件 |
| 图像处理 | OpenCV + NumPy | 窗宽窗位调整、尺寸归一化 |
| 可解释性 | pytorch-grad-cam | 生成CAM热力图 |
| 结节定位 | OpenCV轮廓检测 | 从CAM热力图提取结节边界框 |
| 可视化 | matplotlib | 热力图保存与展示 |
